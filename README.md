## Лабораторная работа №6: Рефакторинг и Code Smells

# Проблемы качества кода в исходной версии:

1. Длинная функция process_checkout с высокой сложностью
2. Смешение различных ответственностей в одной функции
3. Магические числа разбросаны по коду
4. Сложная логика расчета скидок с вложенными условиями
5. Неоптимальные проверки типов
6. Отсутствие разделения на уровни абстракции

# Примененные рефакторинги:

1. Вынесение констант в отдельные переменные
2. Разделение логики на отдельные функции
3. Упрощение проверок с использованием isinstance
4. Создание вспомогательных функций для каждой операции
5. Улучшение читаемости за счет последовательных вызовов

# Изменения в структуре кода:

- parse_request - извлечение данных из запроса
- validate_request - валидация входных параметров
- calculate_subtotal - расчет промежуточной суммы
- calculate_discount - расчет скидки по купону
- calculate_tax - расчет налога
- generate_order_id - генерация идентификатора заказа

# Результаты рефакторинга:

- Функция process_checkout сократилась с 60+ строк до 20 строк
- Код стал более читаемым и понятным
- Упростилось тестирование отдельных компонентов
- Упростилась модификация логики расчета скидок
- Все тесты продолжают проходить без изменений
